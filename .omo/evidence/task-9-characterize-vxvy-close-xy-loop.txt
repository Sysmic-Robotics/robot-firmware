Design notes
--------------------------------------------------------------------
- Rotation test runs through the public step() with kp=1/ki=0 so the output
  IS the rotated error (clamped at 2.0 > sqrt(2), no clipping).
- wrap() boundary convention is the while-loop style required by the task:
  wrap(3*pi) == -pi and wrap(-3*pi) == pi. The upper-boundary loop owns
  values >= pi; the lower-boundary loop only runs when the first did not,
  so the two boundaries do not fight at 3*pi / -3*pi.
- Stale guard is timestamp-based (state.last_update vs Instant::now(),
  threshold 2 x 16.67 ms), unlike the T8 Lua frame counter, per G6.
- The 5th send_velocity arg carries the ABSOLUTE field-frame theta target
  (wrapped to [-pi,pi]), NOT omega — the firmware velocity loop holds theta.
- Persistent per-robot PositionPID instances live in Radio::position_pids so
  integral state survives across frames (same pattern as face_pids).
